# Итерация 6: Ключ-дверь

## Заголовок
Выход заблокирован дверью. Нужно сначала найти ключ 🗝️, а затем сундук и выход (порядок: ключ → сундук → выход). Без ключа к выходу не пройти.

## Мотивация
Текущая цель «сундук → выход» стала привычной. Ключ добавляет второй промежуточный этап, заставляет исследовать лабиринт глубже и даёт дополнительную мета-цель без изменения тумана (радиус 1) и без новых зависимостей.

## Конкретное ТЗ
1. Добавить клетку ключа 🗝️ в генерацию (рядом с сундуком, distinct).
2. Выход 🚩 изначально «заперт»: при попадании без ключа — сообщение «Дверь закрыта, нужен ключ», ход не засчитывается как позиция с кладом, можно уйти.
3. Подбор ключа: carryingKey = true, сообщение «Ключ взят», ключ исчезает с поля.
4. Чтобы вынести сундук через выход, нужен ключ (carryingKey). Иначе — «Сначала возьмите ключ».
5. Прогрессия уровней не ломается: ключ генерируется на каждой партии, перекрытие с другими объектами исключено.
6. Туман радиус 1 не расширяется. Ключ виден только в радиусе 1.

## Критерий приёмки
- Ключ есть на поле, подбирается, исчезает.
- Выход без ключа не пускает (сообщение).
- С ключом можно вынести сундук — победа.
- node --check → JS OK.
- Не ломает регрессии: туман, старые механики, звук, анимация, мини-карта, рекорды, сохранение.

## Риски
- Порядок подбора (ключ/сундук) может быть любым — оба варианта работают.
