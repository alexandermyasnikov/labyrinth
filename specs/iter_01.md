# Итерация 1: Компас к цели + пульс-подсказка направления + прогрессия уровней сложности

## Заголовок
Добавить компас в HUD, указывающий направление к активной цели (сундук или выход), периодическую пульс-подсказку направления в тумане и постепенное нарастание сложности с каждой победой.

## Мотивация
Сейчас игрок блуждает вслепую по карте 10x10 без малейшего намёка, есть ли движение к цели. Это главный источник фрустрации и причины бросить игру: даже удачные ходы неощутимы. Компас даёт ощущение прогресса и целенаправленности, пульс-подсказка раз в N ходов подталкивает, не раскрывая карту, а прогрессия сложности даёт повод переигрывать после победы. Все три механики просты и не трогают существующую логику тумана. Эффект/стоимость максимальны для итерации 1.

## Конкретное ТЗ

### 1. Активная цель — новая функция `activeTarget()`
Добавить в блок «Состояние» функцию:
```js
function activeTarget(){
  // если игрок несёт сундук — цель выход, иначе сундук
  return carrying ? exitPos : chest;
}
```
Существующая логика `carrying` остаётся нетронутой. Цель переключается автоматически при подборе сундука.

### 2. HUD — компас в верхней панели
В HTML внутри `.hud` после `<span>Клад: ...</span>` добавить:
```html
<span>Компас: <b id="hud-compass">?</b></span>
```
В JS получить элемент `const hudCompass = document.getElementById('hud-compass');`.

В `updateHUD()` добавить вычисление направления и запись в `hudCompass`:
```js
const [ar, ac] = activeTarget();
const [pr, pc] = player;
let dir = '';
if (ar === pr && ac === pc) dir = '●';            // цель рядом
else if (ar < pr) dir = '⬆';                       // цель выше
else if (ar > pr) dir = '⬇';
else if (ac < pc) dir = '⬅';
else if (ac > pc) dir = '➡';
hudCompass.textContent = dir;
```
Если цель на той же строке, но дальше, работает ветка по столбцу — компактно и однозначно. Символы-стрелки (U+2B06 и т.п.) уже есть в шрифте, новых зависимостей нет.

### 3. Пульс-подсказка направления в тумане
Добавить счётчик ходов: `let moves = 0;` в блок «Состояние».

Увеличивать `moves++` в `tryMove()` (после успешного хода, до/после `render()` — без разницы, но до вызова `render()`).

В `render()`, после отрисовки игрока (блок «игрок — всегда в центре»), добавить: если `moves % 12 === 0` (каждый 12-й ход) — нарисовать стрелку от игрока в сторону `activeTarget()` в углу канваса:
```js
if (moves % 12 === 0){
  const [ar, ac] = activeTarget();
  const [pr, pc] = player;
  let dx = 0, dy = 0;
  if      (ar < pr) dy = -1;
  else if (ar > pr) dy =  1;
  else if (ac < pc) dx = -1;
  else if (ac > pc) dx =  1;
  ctx.save();
  ctx.font = '46px serif'; ctx.textAlign='center'; ctx.textBaseline='middle';
  ctx.globalAlpha = 0.85;
  ctx.fillText(dx===0&&dy===0 ? '🏆' : (dy<0?'⬆':dy>0?'⬇':dx<0?'⬅':'➡'), C - 120*dx, C - 120*dy);
  ctx.restore();
}
```
Стрелка появляется на 1 ход и исчезает при следующем ходу (moves становится 13). Это мягкая помощь, не раскрывающая туман.

### 4. Прогрессия сложности — переменная `level`
Добавить `let level = 1;` в блок «Состояние».

В `endWin()` перед `msg(...)`:
```js
level++;
info('Уровень ' + level + '! Сложность растёт.');
```
В `endLose()` сбросить `level = 1;`.

В `init()` применить уровень к генерации. Сейчас объекты фиксированы:
```js
river = cells.slice(3,7); holes = cells.slice(7,11);
arsenal = cells.slice(11,13); hospital = cells[13];
trap = cells.slice(14,16); bear = cells[16];
```
Заменить константы на производные от `level`:
```js
// базовые наборы — маркеры структуры, совместимы с inList()
river = cells.slice(3,7); holes = cells.slice(7,11);
arsenal = cells.slice(11,13); hospital = cells[13];
// сложность растёт с уровнем
const extraTrap  = Math.min(level - 1, 3);                       // с 1 до 3 доп. ловушек
const extraBear  = Math.min(level - 1, 2);                       // с 1 до 2 доп. медведей
const bearCell   = cells.slice(14, 16);
const extraCells = cells.slice(16, 16 + extraTrap + extraBear);
trap = cells.slice(14, 14 + 2 + extraTrap);                      // базовые 2 + доп. ловушки
bear = [cells[16]];                                              // первый медведь — как сейчас (одиночный объект)
// остальные дополнительные медведи — см. пункт ниже про массив
```

### 5. Массив медведей вместо одного (необходимо для доп. медведей)
Текущий `bear` — одна клетка `[r,c]`. Для нескольких медведей без поломки логики ввести массив `bears` и совместимую обёртку:
- Добавить `let bears = [];` в «Состояние».
- В `init()`: `bears = <список из (2 + extraBear) клеток>`. Первый медведь — `cells[16]`, остальные — следующие уникальные из `cells`.
- Вместо `bear` в `bearTurn()` и `render()` использовать `bears`:
  - `bearTurn()`: пройти циклом `for (const b of bears)` — для каждого применить текущую логику движения и проверки контакта с игроком (вынести тело текущей функции в цикл; болезнь: каждый медведь ходит один раз за ход — это сохраняет текущее поведение одиночного медведя, только в цикле).
  - `render()`: цикл по `bears` для отрисовки медведей.
- Все упоминания `bear` в `init`, `bearTurn`, `render`, `cellSymbol`(нет) заменить согласованно. Проверить grep.

Примечание: чтобы не растиражировать код, тело текущей `bearTurn()` просто оборачивается в цикл по `bears` с заменой `bear` → `b`.

## Критерий приёмки
1. В HUD появился «Компас»: стрелка⬆⬇⬅➡ указывает на сундук, пока его не взяли; после взятия сундука автоматически переключается на выход; при нахождении на цели — `●`.
2. Каждый 12-й ход в углу канваса вспыхивает стрелка направления к активной цели; на следующем ходу исчезает.
3. После победы на экране «Уровень N» и следующая партия сложнее: растёт число ловушек (до 5) и медведей (до 3); медведи движутся по одной клетке за ход как прежде.
4. После проигрыша уровень сбрасывается до 1 — следующая партия базовой сложности.
5. Регрессия: без изменений карты, тумана, рек, дырок, арсенала, госпиталя, бомб, победы/проигрыша. Игра проходит так же, как раньше, только с новой подсказкой и прогрессией.

## Риски/ненужное
- Доп. количество медведей требует аккуратной замены `bear`→`bears`; если хочется минимального риска, можно на итерацию 1 оставить одного медведя и добавить только ловушки — но тогда пункт 5 не нужен. Код стабилен в обоих вариантах.
